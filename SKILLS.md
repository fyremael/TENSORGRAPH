# SKILLS: TENSORGRAPH

Local tools for the TENSORGRAPH Rewriting Compiler (formerly TENSORGRAPH).

> [!IMPORTANT]
> All Python operations MUST use the `.venv` or `uv run`.

### Optimization Trace
- **Path**: `tensorgraph/cli/optimize_fx.py`
- **Cmd**: `uv run python -m tensorgraph.cli.optimize_fx --help`

### Benchmark Suite
- **Path**: `benchmarks/regression.py`
- **Cmd**: `uv run python benchmarks/regression.py`
