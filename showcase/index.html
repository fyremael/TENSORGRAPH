The Mental Model

▶ Objects & Morphisms

Programs are represented as typed string diagrams:

# Objects = Types Tensor = Obj("Tensor") # Morphisms = Typed Processes Id(Tensor) # Identity: T → T Box("Linear") # Primitive op Seq(f, g) # Sequential: f ; g Par(f, g) # Parallel: f ⊗ g
▶ The E-Graph

An equivalence graph compactly represents many equivalent programs:

┌─ E-Class 1 ───────────────────────┐ │ • (f ; g) ; h │ │ • f ; (g ; h) [associativity] │ └───────────────────────────────────┘ │ ▼ (references) ┌─ E-Class 2 ───────────────────────┐ │ • g ; h │ └───────────────────────────────────┘
▶ Rewrite Rules

Define 2-morphisms as typed equivalences:

# Pattern-based rewriting Rewrite( name="FuseOps", lhs=PSeq(PBox("f"), PBox("f")), rhs=PBox("f"), ) # Rule: f ; f ≡ f
▶ Saturation & Extraction

Phase 1: Saturate — Apply all rules until fixed point.
Phase 2: Extract — Select lowest-cost program.

saturate(eg, rules, iters=10) best = Extractor(eg).extract(root)
